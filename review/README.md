# 人工复核

盲评样本有 6 道题、18 条回答，覆盖事实题、多跳题和拒答题，同题包含三种系统的回答。2B 的 3 条均为事实题，4B 覆盖三类各 1 条。两位评分员已先独立评分，交齐后再打开对应表。样本用于错误分析和评审校准。

每条记录打四个 0/1 分。

- 正确性。医学事实、药物、剂型、单位和条件与参考答案一致。
- 完整性。覆盖参考答案中的主要事实和必要限定。无答案题需清楚表达证据不足。
- 证据忠实度。对有引文的回答，核对 `[C1]` 等实际编号，确认相应段落支持主张。可回答的闭卷答案记为 N/A。
- 无证据主张。答案出现参考和给定证据均无法支持的实质主张时记 1。没有主张的合理拒答记 0。

记录格式为“回答编号 / 正确 / 完整 / 忠实 / 无证据主张 / 说明”。先保留独立评分，再报告分歧数量和讨论后的汇总。显式引用编号格式合法与证据忠实度分别计分。

评分时各用一份独立评分表，对照 [盲评样本](blind_sample.md) 填写。两份评分表交齐后再查看 `unblind_key.json`。
